# 条目、检查点与持久化测试用例

状态：领域/仓储已覆盖，不代表已接入 Feed 或条目 HTTP。映射见 [覆盖表](coverage.md)。

| 用例编号 | 功能 | 前置条件 | 操作 | 预期 |
| --- | --- | --- | --- | --- |
| TC-SUB-006-01 | SUB-006 | 有来源，无条目 | discover 后同事务添加条目和修订 | 修订 1 可读，数据往返一致 |
| TC-SUB-006-02 | SUB-006 | 有条目及当前修订 | 先观察相同元数据，再观察变更内容 | 相同不增修订；变化才连续追加 |
| TC-SUB-006-03 | SUB-006 | 有当前条目 | 用其他条目或过期修订 observe | 拒绝且不推进内存状态 |
| TC-SUB-006-04 | SUB-006 | 已有身份 | 同来源重复插入；再用其他来源插入同身份 | 同来源重复报错，不同来源允许 |
| TC-SUB-006-05 | SUB-006 | 同条目被两个工作单元读取 | 竞争追加修订 | 过期更新失败，不遗留额外修订 |
| TC-SUB-006-06 | SUB-006 | 已有条目 | 推进版本却不传修订，或覆盖历史 | 拒绝，不破坏版本对应关系 |
| TC-SUB-007-01 | SUB-007 | 已有条目及多个修订 | 按来源列条目、读取历史列表及不存在的修订号 | 当前修订号正确、历史内容正确，不存在修订返回 None |
| TC-SUB-008-01 | SUB-008 | 旧地址版本，后续变更地址 | 用旧 expected_address_version 更新检查点 | 拒绝旧结果；单纯改名不改变地址版本 |
| TC-SUB-008-02 | SUB-008 | 已有成功检查点 | 写入无时区或倒退时间 | 拒绝，不伪造新的成功状态 |
| TC-DB-001 | 跨用例事务 | 临时数据库 | 不 commit 或中途抛异常 | 来源/条目/修订写入回滚 |
| TC-DB-002 | 持久化约束 | 临时数据库 | 无来源外键插入、非法修订号 | 约束拒绝；外键错误不伪装成重复 |
| TC-DB-003 | 会话边界 | 从其他工作单元取得领域对象 | 在新工作单元直接 save | 拒绝脱离当前工作单元的实例 |
| TC-DB-004 | 迁移/启动 | 全新临时库 | 升级、应用写入、重启读回、迁移降级 | 表和数据契约正确，各测试按独立路径验证 |

未覆盖的未来用例：Feed 超时/304/重定向、SSRF、Feed 解析限额、在途关闭、Feed 批量提交失败、事件重复消费。OPML 安全和逐项失败验证见 [导入用例](opml-cases.md)。
当前仓储测试覆盖来源分页，但尚未专门断言条目和历史列表的多页边界；不能将其视为已完整覆盖。
它们需要在对应功能实现时加入自动化，而不是用领域方法测试替代。
